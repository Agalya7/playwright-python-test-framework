# Playwright Python Test

## Overview
A scalable end-to-end test automation framework built using Playwright, Python and pytest. The project demonstrates a maintainable automation architecture suitable for testing modern web applications.

## Tech Stack
- Python
- Playwright
- pytest
- GitHub Actions

## Framework Features
- Page Object Model
- Cross-browser testing
- Parallel execution
- Parameterized tests
- Screenshot capture on failure
- HTML test reporting
- CI integration

## Architecture
Tests

  ↓

Page Objects

  ↓

Playwright

  ↓

Web Application

## Running Tests
> pip install -r requirements.txt
>
> pytest
